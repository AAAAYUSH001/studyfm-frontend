# 🎧 StudyFM: AI-Powered Study Companion

**[Live Demo](https://studyfm-frontend-xx.vercel.app/)** | **[Backend Repository](https://github.com/AAAAYUSH001/studyfm-backend)**

StudyFM is a full-stack web application designed to eliminate the friction of consuming large academic documents. It processes PDFs and raw text, leverages Google's Gemini AI to extract key insights, and generates synchronized audio summaries for an on-the-go learning experience.

## ✨ Features
* **Smart Document Parsing:** Upload complex study materials, lecture slides, or pasted notes.
* **AI Summarization:** Utilizes Google Gemini to distill long-form content into concise, high-yield summaries.
* **Text-to-Speech (TTS):** Converts AI-generated text into high-quality audio tracks using the Google Cloud TTS API.
* **Modern UI/UX:** A responsive, dark-mode focused interface built for both desktop and mobile web.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, Tailwind CSS (Deployed on Vercel)
* **Backend:** Node.js, Express.js (Deployed on Render)
* **AI & APIs:** Google Gemini AI API, Google Text-to-Speech API
* **Architecture:** RESTful API design, CORS management, Environment Variable security
